SmartGrade — Sistema Acadêmico Inteligente de Notas, Faltas e Análise Preditiva

O SmartGrade é uma aplicação desktop desenvolvida em Java com interface gráfica em Swing, projetada para a gestão de registros acadêmicos, controle de frequência e lançamento de avaliações. O sistema adota a arquitetura Model-View-Controller (MVC) e utiliza o banco de dados relacional MySQL para garantir a integridade dos dados escolares.
O diferencial do projeto é a integração de uma Tecnologia Emergente por meio de um módulo de Machine Learning Preditivo. A aplicação analisa o desempenho histórico de notas e o percentual de faltas acumuladas em tempo real, prevendo precocemente a probabilidade de evasão ou reprovação dos alunos antes do fechamento do semestre letivo.

🎯 Funcionalidades Principais
 Gestão Cadastral: Cadastro, consulta e manutenção de alunos, turmas e disciplinas.
 Diário de Classe & Avaliações: Lançamento de notas parciais (provas, trabalhos) e registro de frequência/faltas.
 Cálculo Automatizado: Processamento em tempo real de médias ponderadas, percentuais de presença e status acadêmico (Aprovado, Reprovado por Nota, Reprovado por Falta).
 Módulo Preditivo (IA): Algoritmo de classificação que categoriza o nível de risco de cada estudante (🟢 Baixo Risco, 🟡 Médio Risco / Atenção, 🔴 Alto Risco).
 Dashboard de Indicadores: Painel visual consolidado com alertas imediatos para intervenção pedagógica e acompanhamento da coordenação.
 
🛠️ Tecnologias e Ferramentas
 Linguagem: Java (JDK 21)
 Interface Gráfica: Java Swing
 Arquitetura: MVC (Model-View-Controller) com padrão DAO (Data Access Object)
 Banco de Dados: MySQL 8.0 (persistência via driver JDBC)
 Tecnologia Emergente: Machine Learning Preditivo (Classificação / Análise de Risco)
 Ambiente de Desenvolvimento: Eclipse IDE / VS Code
 Versionamento: Git e GitHub
